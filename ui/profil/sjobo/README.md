# Sjöbo kommuns logotyp

Filerna i den här mappen är Sjöbo kommuns logotyp. Logotypen ägs av Sjöbo kommun och
får bara användas i, av eller i samråd med kommunens verksamhet.

**Andra kommuner som kopierar Aibi ska byta ut den här mappen mot sin egen profil och
får inte använda Sjöbos logotyp.** Peka om `profil.logotyp` i inställningarna till
den egna mappen.

| Fil | Variant | Använd när |
|---|---|---|
| `sjobo-liggande-farg.svg` | Liggande, färg, vektor | Standard på ljus bakgrund. Skalas utan kvalitetsförlust. |
| `sjobo-liggande-farg.png` | Liggande, färg, 461 px bred | Reserv om svg inte kan användas. |
| `sjobo-liggande-negativ.png` | Liggande, vit | Mörk eller färgad bakgrund. Ser tom ut mot vitt, det är väntat. |
| `sjobo-staende-farg.png` | Stående, färg | Smala ytor. |
| `sjobo-staende-negativ.png` | Stående, vit | Smala ytor på mörk bakgrund. |

Regler ur Grafisk manual 2026.1, se `docs/GRAFISK-PROFIL.md`:

- Logotypen placeras till höger, gärna nere till höger. Björnen ska titta in mot
  innehållet. Ligger logotypen till vänster tittar björnen ut, och det är fel.
- Frizon minst 25 procent av logotypens höjd.
- Skala aldrig ojämnt, beskär aldrig, ändra aldrig färger.

Kontrollsumma för vektorfilen: ta bort alla blanktecken ur filen och räkna sha256.
Summan ska vara `1424385b55a32a108900cf740e76af3ff90fc7fb20af9787f79c0da7896ee351`.
