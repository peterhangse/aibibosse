Katalogimport — BSKO (biblioteksso.se)

Ladda upp en exportfil från Bibliotek SkåneSydost (Axiell Arena). Varje rad blir ett dokument bok-<isbn> (ISBN-nycklat och idempotent — samma källa körs om utan duplikat). Böcker med flera upplagor visas som "andra utgåvor" via meta.utgavor.

📚

eller klicka för att välja fil (CSV från BSKO stöds)
